# IoT Application Design Workshop

**One Day Hands-on Workshop** organized by **EMBED Club**, Department of Computer Science and Engineering, P.A. College of Engineering.

**Date Attended**: 26 May 2025

---

## Workshop Overview

I attended a full-day practical workshop focused on designing and building real-world IoT applications using the ESP32 development board. The session was highly interactive and hands-on, covering everything from basic hardware programming to cloud-connected voice control systems. It gave me strong foundational knowledge in embedded IoT development.

## Topics Covered

- Introduction to ESP32 microcontroller and basic LED blinking
- Interfacing LCD Display with ESP32 for data visualization
- Working with DHT Sensor (temperature & humidity) and Ultrasonic Sensor with Relay control
- Building simple Home Automation projects using ESP32
- Voice Control implementation using Sinric Pro platform

## Code Examples Included

This repository contains all the code sketches and examples I worked on during the workshop:

- Basic ESP32 LED blinking and GPIO control
- LCD Display projects for showing sensor data
- DHT Sensor integration for temperature and humidity monitoring
- Ultrasonic Sensor with Relay for distance-based automation
- Voice-controlled IoT projects using Sinric Pro

## Technologies Used

- **Hardware**: ESP32 Development Board
- **Development Environment**: Arduino IDE
- **Sensors & Modules**: DHT Sensor, Ultrasonic Sensor, Relay Module, LCD Display
- **Cloud Platform**: Sinric Pro (for voice control)
- **Programming Language**: C++ (Arduino framework)

## What I Learned

- Practical understanding of ESP32 architecture and its GPIO pins
- How to interface and program different sensors and actuators
- Basics of IoT communication protocols and cloud integration
- Importance of proper code structure, debugging, and hardware troubleshooting
- Real-world application design thinking — moving from simple LED projects to complete IoT solutions
- How voice control can be implemented in embedded systems using platforms like Sinric Pro

This workshop significantly improved my confidence in working with hardware and gave me a strong foundation in IoT application development.

## Future Plans

- Build more advanced IoT projects using the concepts learned
- Integrate these skills with my full-stack web development knowledge
- Explore more cloud platforms and advanced sensors
